# Google Sheets Database Template — Eki Launch Automation

This document outlines the detailed column requirements and formula definitions for the Google Sheets database tabs needed to support the Eki launch automation system.

---

## 📅 Summary of Database Tabs
The database contains seven (7) tabs. Ensure the sheet is named `Eki Launch Database` and all tabs are named exactly as shown:

1.  **Leads**: Tracks all user acquisitions, segments, and onboarding statuses.
2.  **Content Calendar**: Houses the pre-seeded launch posts structure (30-day strategy).
3.  **Content Drafts**: Working drafts generated by AI for review, approval, and publishing.
4.  **Waitlist**: Early signups prior to public launch, capturing queue ordering.
5.  **Feedback**: User review survey scores, ratings, and customer comments.
6.  **Analytics**: Weekly growth report snapshots.
7.  **Referrals**: Individual referral links clicked, tracking attribution points.

---

## 1. Tab: Leads
- **Purpose**: Central database for landing page signups.
- **Columns (Headers in Row 1)**:
  - `lead_id` (Text / ID): Auto-generated unique lead ID (e.g., `L-1001`).
  - `email` (Text / Email): Primary contact email.
  - `name` (Text): Full user name.
  - `user_segment` (Text): Segment options: `Vendor (Domestic)`, `Vendor (Exporter)`, `Buyer (Local)`, `Buyer (International)`.
  - `country` (Text): Country of operation (e.g., `Nigeria`, `Italy`, `Ghana`).
  - `foodstuff_specialty` (Text): Categories of interest (e.g., `Spices`, `Tubers`, `Palm Oil`).
  - `source` (Text): Channel source (e.g., `tiktok`, `instagram`, `linkedin`, `referral`).
  - `interest_level` (Text): Segment values: `Low`, `Medium`, `High`, `Ready to Onboard`.
  - `referral_code` (Text): Referral code used at signup.
  - `signup_date` (Date): Registration date (`YYYY-MM-DD`).
  - `status` (Text): Funnel states: `New`, `Welcome Sent`, `Active`, `Inactive`, `Churned`.
  - `last_contacted` (Date/Time): Date and time of last automated email.
  - `notes` (Text): Team comments.

---

## 2. Tab: Content Calendar
- **Purpose**: Pre-set plan for content execution.
- **Columns (Headers in Row 1)**:
  - `day_number` (Number): Day index (1 to 30).
  - `phase` (Text): Project launch phases: `Pre-Launch Hype`, `Launch Week`, `Post-Launch Growth`.
  - `pillar` (Text): Content strategy category: `Problem Awareness`, `Behind the Scenes`, `Social Proof`, `Education`, `Community`.
  - `suggested_platform` (Text): Targets: `TikTok`, `Instagram Reels`, `X/Twitter`, `LinkedIn`.
  - `topic_brief` (Text): Brief topic or story angle.
  - `suggested_hook` (Text): Scroll-stopping starter text.
  - `cta` (Text): Main call-to-action link/request.
  - `target_audience` (Text): Target reader: `Vendors`, `Buyers`, `Exporters`, `All`.

---

## 3. Tab: Content Drafts
- **Purpose**: AI draft container for the approval loop.
- **Columns (Headers in Row 1)**:
  - `draft_id` (Text / ID): Unique draft code (e.g., `D-201`).
  - `day_number` (Number): Mapped from Content Calendar.
  - `platform` (Text): Specific target channel (e.g., `TikTok`, `LinkedIn`).
  - `hook` (Text): Text scroll-stopper.
  - `caption` (Text): Drafted post copy.
  - `hashtags` (Text): Curated keywords (e.g. `#EkiMarket #AfricanFoodstuff`).
  - `video_script` (Text): Video storyboard instructions or voiceover cues.
  - `status` (Text): System state: `Draft`, `Approved`, `Needs Revision`, `Published`, `Notification Sent`.
  - `approval_date` (Date/Time): Approval timestamp.
  - `published_date` (Date/Time): Date published.
  - `publish_time` (Date/Time): Time published.
  - `row_number` (Number): Spreadsheet row index (for updates).
  - `published` (Boolean): `TRUE` or `FALSE`.

---

## 4. Tab: Waitlist
- **Purpose**: Launch list queue manager.
- **Columns (Headers in Row 1)**:
  - `email` (Text / Email): Early subscriber email.
  - `name` (Text): Subscriber name.
  - `position` (Number): Early queue number.
  - `referral_code` (Text): User's unique sharing code.
  - `referrals_count` (Number): Total referred signups.
  - `user_type` (Text): `Vendor` or `Buyer`.
  - `signup_date` (Date): Waitlist date.

---

## 5. Tab: Feedback
- **Purpose**: Collect review ratings and notes.
- **Columns (Headers in Row 1)**:
  - `feedback_id` (Text / ID): Mapped unique ID.
  - `email` (Text / Email): Client email.
  - `user_role` (Text): Role segment (`Vendor` or `Buyer`).
  - `rating` (Number): Rating stars (1 to 5).
  - `primary_value` (Text): Client's favorite feature.
  - `pain_point` (Text): System/operational difficulties.
  - `would_recommend` (Boolean): NPS advocate status (`TRUE` / `FALSE`).
  - `submitted_date` (Date): Submission date.
  - `action_taken` (Text): Internal operations: `Pending Review`, `Resolved`, `Forwarded to Dev`.

---

## 6. Tab: Analytics
- **Purpose**: Weekly snapshot metrics storage.
- **Columns (Headers in Row 1)**:
  - `report_date` (Date): Calculation date (`YYYY-MM-DD`).
  - `week_start` (Date): Analytics start range (`YYYY-MM-DD`).
  - `total_leads` (Number): Total leads to date.
  - `new_leads` (Number): Leads created during the 7-day range.
  - `conversion_rate` (Number): Leads converted to Active.
  - `content_published` (Number): Posts published.
  - `avg_feedback_rating` (Number): Average feedback score.
  - `waitlist_size` (Number): Total queue count.
  - `total_referrals` (Number): Lifetime referral signups.
  - `wow_growth` (Number): Week-over-week percentage change.

---

## 7. Tab: Referrals
- **Purpose**: Audit log for points tracking.
- **Columns (Headers in Row 1)**:
  - `referral_id` (Text / ID): Unique lookup code (e.g., `R-5001`).
  - `referrer_email` (Text / Email): Account holding the parent referral code.
  - `referred_email` (Text / Email): New signup email.
  - `referral_code` (Text): Referral code used.
  - `timestamp` (Date/Time): Date/Time of registration.
  - `points_credited` (Number): Score value (usually `1`).
  - `status` (Text): Processing state: `Credited`, `Pending Verification`.
