# Historical n8n architecture note

n8n is not part of the supported production runtime. The application runs on
the native TypeScript API, PostgreSQL, Redis/BullMQ, and TypeScript worker;
see [NATIVE_AUTOMATION.md](NATIVE_AUTOMATION.md) and [ARCHITECTURE.md](ARCHITECTURE.md).

This filename is retained only so old links resolve. The old n8n deployment,
credential-sync, workflow-import, and supervisor instructions are historical
evidence and must not be used for deployment or staging acceptance.
